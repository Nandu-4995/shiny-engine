# 🚀 Shiny Engine - Full-Stack Blog Application

A responsive, full-stack web application featuring dynamic DOM manipulation, smooth CSS animations, and full CRUD (Create, Read, Update, Delete) functionality. Built during a 14-day Full-Stack Development Internship at Codomax Digital Solutions.

## 🔗 Live Demo
**[View the Live Frontend UI Here](https://nandu-4995.github.io/shiny-engine/)** 
*(Note: The live deployment hosts the static frontend via GitHub Pages. To test the backend Node.js CRUD operations, please follow the local installation instructions below).*

## ✨ Key Features
*   **Complete CRUD Operations:** Users can dynamically create, read, update, and delete blog posts.
*   **RESTful API Integration:** Frontend communicates seamlessly with a custom Node.js/Express backend using the native JavaScript `Fetch API`.
*   **Responsive UI/UX:** Mobile-first design utilizing CSS media queries for perfect rendering across all devices.
*   **Dynamic Animations:** Custom `@keyframes` and smooth hover transitions elevate the user experience.
*   **Graceful Error Handling:** Asynchronous error trapping ensures the UI provides professional feedback if the backend server is offline.

## 🛠️ Tech Stack
*   **Frontend:** HTML5, CSS3, Vanilla JavaScript (ES6+)
*   **Backend:** Node.js, Express.js
*   **Deployment:** Git, GitHub Pages
